# S5-nano

Modelo de linguagem da Maritaca AI.

As respostas e correções das avaliações ficam em [results](results/README.md),
organizadas por modelo, benchmark e modo de inferência.

São 11 modelos, 426 conjuntos de resultados e 1.079.754 respostas selecionadas.
Cada conjunto inclui uma nota, os arquivos de respostas e a cobertura dos
metadados recuperados. Thinking e Instruct ficam em pastas separadas.

Para conferir os arquivos e recalcular as notas, instale `requirements.txt` e
execute `python scripts/validate_results.py`. A conferência funciona localmente,
sem chamadas a APIs.

Este repositório permanece privado.
